# 딜레마 제로 (Dilemma Zero)

> 앞 신호의 남은 시간과 내 차의 속도·거리를 계산해, 노란불이 켜지기 전에 순정 내비 위의 색과 "속도 줄이세요" 한마디로 미리 멈출 준비를 시켜 주는 교차로 안전 코치

현대자동차그룹 차량용 앱 개발 공모전 2026 출품작 · Pleos Connect (Android Automotive)

---

## 1. 무엇을 하는 앱인가

| 상황 | 딜레마 제로가 하는 일 |
|---|---|
| 평소 (여유) | 아무것도 하지 않음 — 운전자는 순정 내비만 봄 |
| 지금 속도면 황색 순간 편하게 못 멈춤 | 내비 화면 가장자리 **노란 테두리 3초** + "앞 신호, 속도 줄이세요" |
| 세게 밟아야 멈출 수 있음 / 곧 황색 | **빨간 테두리** + "정지 준비" |
| 주차(P) | 이번 주행 **교차로 안전 점수** 요약 + **내 브레이크 습관**(반응시간·편안한 감속) |

- 남은 초(숫자)는 말하지도 보여주지도 않고, "통과하세요"는 어떤 경우에도 안내하지 않습니다.
- 신호를 모르거나, 위치와 속도가 맞지 않거나, 회전 중이거나, 급제동으로도 못 멈출 거리면 안내하지 않습니다.
- **안내 모드**: 기본(반응 1.0초·감속 3.0 m/s²) / 여유: 초보·화물차(1.5초·2.0 m/s²) — 주차 중에만 바꿀 수 있습니다.
- **브레이크 습관 학습**: 안내 후 처음 브레이크를 밟기까지의 반응시간과 정지까지의 감속도를 기록합니다(Vehicle SDK 브레이크 페달 + 차량 속도). 각각 5번 넘게 모이면 "학습됨"이 되고, **안내가 더 일찍 나오는 쪽으로만** 판정에 반영합니다. 시연 파일 재생 중에는 반영하지 않습니다.

## 2. 실행 방법

### 가장 빠른 확인: 시연 파일 재생 (네트워크·GPX 필요 없음)

1. Pleos Connect 에뮬레이터를 켜고 APK를 설치합니다.
   ```
   adb install -r apk/<APK 파일명>.apk
   ```
2. 기어 **P** 상태에서 앱 **딜레마 제로**를 실행하고, 권한 창이 뜨면 모두 허용합니다.
3. (선택) 순정 내비 위 **테두리 안내**를 보려면 아래 명령을 한 번 실행합니다. 실행하지 않으면 테두리 대신 알림 팝업으로 안내합니다.
   ```
   adb shell appops set --user 10 com.hmgapp.yellowlightcoach SYSTEM_ALERT_WINDOW allow
   ```
   에뮬레이터를 다시 켜거나 앱을 다시 설치하면 이 권한이 풀릴 수 있습니다. 앱의 **개발자 보기**에 권한 상태가 표시됩니다.
4. 운전 화면 오른쪽 위 **개발자 보기** → **▶ 시연 파일 재생**을 누릅니다.
   - 울산 실제 신호를 기록한 3분 38초 주행이 재생됩니다 (화면에 "시연용 재생 데이터" 표시).
   - (선택) 계기판 표시를 맞추려면 Virtual Console에서 기어 D · 60km/h로 둡니다. 재생 중에는 앱이 콘솔 값 대신 기록된 값을 씁니다.
5. 하단 독에서 **내비(▲)** 화면으로 이동해 기다립니다.
   - 재생 약 0:11, 2:32 — 빨간 테두리 "정지 준비"
   - 재생 약 2:49 — 노란 테두리 "앞 신호, 속도 줄이세요" → 2:57 빨간 테두리 "정지 준비" (현대백화점사거리)
6. 재생이 끝나기 전에 Virtual Console을 **P**로 바꿔 두면, 끝나는 순간 **교차로 안전 점수** 카드가 나옵니다 (시연 기록 기준 60점).

### 브레이크 습관 시험 (Virtual Console 필요)

1. 아래 "실시간 주행"의 Virtual Console 연결을 먼저 합니다. Virtual Console 창을 에뮬레이터 옆에 두면 편합니다.
2. 기어 **P**에서 **개발자 보기**를 연 뒤, Virtual Console을 기어 **D** · **60km/h**로 둡니다 (개발자 보기는 그대로 유지됨).
3. **🦶 안내 흉내** → "앞 신호, 속도 줄이세요"가 들리면 **4초 안에** Virtual Console의 **BRAKE**를 누릅니다.
4. 속도를 1초에 10km/h 정도씩 **0**까지 내립니다 (한 번에 0으로 내리면 급정거로 보고 제외).
5. 개발자 보기에 반응시간·감속 기록 횟수가 하나씩 오릅니다. 5번 반복하면 Virtual Console을 **P**로 바꾼 뒤 운전 화면 아래에 "내 브레이크 습관 · … · 학습됨"이 표시됩니다.
   - **🦶 브레이크 기록 지우기**로 처음부터 다시 할 수 있습니다.

### 실시간 주행 (실제 신호 API 사용)

1. 위 1~3 단계 후, Virtual Console을 연결합니다.
   ```
   adb forward tcp:8088 tcp:8088
   ```
   브라우저에서 `http://127.0.0.1:8088` → 아래쪽이 **DDS ONLINE**인지 확인
2. 에뮬레이터 Extended Controls → Location → Routes에서 `test-routes/YLC_west_to_east_60kmh.gpx`를 불러옵니다.
3. Virtual Console에서 기어 **D**, 속도 **60km/h** → GPX 재생 ▶
4. 내비 화면에서 신호 상황에 따라 노랑/빨강 테두리와 음성 안내를 확인합니다. GPX가 끝나면 Virtual Console을 P로 바꿉니다.
   - 신호 타이밍은 실제 신호에 따라 매번 달라서, 안내가 없는 주행도 있습니다.

### 소스에서 빌드

1. Android Studio에서 프로젝트를 엽니다.
2. 프로젝트 루트의 `local.properties`에 공공데이터포털 신호 API 키(Decoding 키)를 넣습니다.
   ```
   SIGNAL_API_KEY=<발급받은 Decoding 키>
   ```
   키는 `local.properties`에만 두며 저장소에 올리지 않습니다.
3. Run 대상으로 Pleos Connect 에뮬레이터를 선택해 실행합니다.

## 3. 테스트 환경 및 필요한 설정

| 항목 | 값 |
|---|---|
| 에뮬레이터 | Pleos Connect v2.1.0 (Android Automotive 14, API 34), 앱 사용자 user 10 |
| 개발 도구 | Android Studio, Kotlin, Jetpack Compose |
| Pleos SDK | Vehicle 2.3.2 · TextToSpeech 3.3.1 · FusedLocation 1.1.3 · NaviHelper 3.0.5 |
| 차량 API | `PERF_VEHICLE_SPEED`, `CarUxRestrictions` |
| 외부 API | 행정안전부 「교통안전 신호등 실시간 정보」 (공공데이터포털) |
| 권한 | 위치, Pleos FusedLocation·TTS·NaviHelper, 차량 속도, 알림, 포그라운드 서비스(위치), (선택) 다른 앱 위에 그리기 |
| 시험 구간 | 울산 공업탑로터리 → 터미널사거리 (신호 교차로 12곳) |
| 단위 테스트 | 37개 — `CoachScenarioTest.kt`(판정 엔진·피로·안내 규칙·위치 불일치·안전 점수·모드 24개), `BrakeLearnerTest.kt`(브레이크 습관 학습·판정 반영 13개) |

참고: 에뮬레이터의 순정 내비는 위치가 고정되어 있어, 내비 다음 회전 안내(TBT)는 내비 위치가 내 위치와 일치할 때만 사용합니다. 시연에서는 방향지시등으로 회전 의도를 판단합니다.

## 5. 구조

```
app/src/main/java/com/hmgapp/yellowlightcoach/
├─ signal/    공공 신호 API, 앱 안 카운트다운(지연 보정)
├─ location/  위치·진행 방향, 앞 교차로 찾기
├─ navi/      순정 내비 다음 회전 안내·제한속도 (NaviHelper)
├─ coach/     판정 엔진, 피로 보정, 안내 규칙, 위치-속도 불일치, 안전 점수, 운전자 모드, 브레이크 습관 학습
├─ voice/     음성 안내 (Pleos TTS) + 오디오 포커스
├─ service/   화면 뒤 동작 (포그라운드 서비스)
└─ demo/      주행 기록·재생
app/src/main/assets/demo.jsonl   시연 파일 (울산 실제 신호 기록)
test-routes/                      시험용 GPX (40km/h, 60km/h)
```

## 6. 개인정보

위치 원본은 차량 밖으로 보내지 않습니다. 주행 기록 파일과 브레이크 습관 값은 앱 내부 저장소에만 저장됩니다.
